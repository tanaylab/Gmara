A list of "lateral" genes, that is, genes whose expression reflects processes which are not specific to the cell type
(e.g., cell cycle or stress). NOTE: This is a preliminary list combining gastrulation and hematopoiesis genes. It may
or (most likely) will not be as useful for very different tissues. YMMV, Caveat emptor, etc.

This directory holds:

* `sources` - The sources of the information we have on this list of genes.
* `names` - The computed names of the genes in the list in the different name spaces.
* `log.txt` - The log from the last time we computed the `names` from the `sources`.
